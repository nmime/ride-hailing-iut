# RideX REST API — Endpoint Reference

Base URL: `https://<your-domain>/api`. Live, interactive documentation is also
served at `/api/docs` (Swagger UI generated by Nest's `@nestjs/swagger`).

> The table below is the source of truth for the report (R4). Keep it in sync
> with the controllers under `apps/api/src/*/`.

| Verb | URL | Auth | Body / Query | 200 / 201 response | Errors |
|---|---|---|---|---|---|
| **Auth** ||||||
| POST | `/auth/signup`           | none | `{ role, full_name, email, phone, password }` | `201 { id, token }` | `409` email/phone in use, `422` validation |
| POST | `/auth/login`            | none | `{ phone, password }`                          | `200 { token }`     | `401` bad credentials |
| **Riders / users** ||||||
| GET  | `/me`                    | bearer | —                                            | `200 User`          | `401` |
| **Drivers** ||||||
| PATCH| `/drivers/{id}/status`   | bearer | `{ status: 'online' \| 'offline' \| 'on_trip' }` | `200 { driverId, status }` | `403` not the owner |
| GET  | `/drivers/nearby`        | bearer | `?lon=&lat=&radius_m=`                        | `200 [Driver…]`      | `422` |
| **Trips** ||||||
| POST | `/trips`                 | bearer (rider) | `{ pickup, dropoff, pickup_address?, dropoff_address? }` | `201 { id, status, requested_at }` | `422` invalid coords |
| GET  | `/trips`                 | bearer | `?status=&limit=`                             | `200 [TripSummary…]` | `401` |
| GET  | `/trips/{id}`            | bearer | —                                              | `200 Trip`           | `404` |
| POST | `/trips/{id}/cancel`     | bearer (rider/driver) | —                                | `200 { id, status }` | `404`, `409` not cancellable |
| **Admin** ||||||
| GET  | `/admin/reports/daily`   | bearer (admin) | —                                     | `200 [DriverDaily…]`| `403` |
| GET  | `/admin/surge`           | bearer (admin) | —                                     | `200 [SurgeZone…]`  | `403` |
| **Health** ||||||
| GET  | `/healthz`               | none | —                                              | `200 { status:'ok' }` | — |
| GET  | `/readyz`                | none | —                                              | `200 …`              | `503` |

## Schemas

```yaml
# These are the canonical TypeScript types served by Swagger.
GeoPoint:
  lat: number   # WGS-84 latitude
  lon: number   # WGS-84 longitude

User:
  id: uuid
  role: rider | driver | admin
  full_name: string
  email: string
  phone: string
  is_active: boolean

Driver:
  user_id: uuid
  status: offline | online | on_trip | suspended
  rating_avg: number
  rating_count: integer
  active_vehicle: Vehicle | null
  last_known_location: GeoPoint | null

Vehicle:
  id: uuid
  plate: string
  make: string
  model: string
  year: integer
  capacity: integer

Trip:
  id: uuid
  rider_id: uuid
  driver_id: uuid | null
  status: requested | matched | in_progress | completed | cancelled_by_rider | cancelled_by_driver | expired
  pickup: GeoPoint
  dropoff: GeoPoint
  requested_at: timestamptz
  matched_at: timestamptz | null
  completed_at: timestamptz | null
  fare_total: number | null
  currency: string

TripSummary:
  id: uuid
  status: TripStatus
  requested_at: timestamptz
  fare_total: number | null
  currency: string

SurgeZone:
  id: uuid
  name: string
  base_multiplier: number    # >= 1.00
  polygon: GeoJSON

DriverDaily:
  driver_id: uuid
  day: date
  trips: integer
  total_km: number
  total_minutes: number
  gross_revenue: number
```

## Error envelope

```json
{
  "statusCode": 422,
  "code":       "validation_error",
  "message":    "pickup.lat must be a latitude",
  "trace_id":   "1a2b3c4d…"
}
```

`trace_id` is the W3C `traceparent` value, propagated end-to-end by
OpenTelemetry. Paste it into Tempo (Grafana → Explore → Tempo) to see the
full call graph for a failed request.

## Sample request / response

`POST /api/trips`

```json
{
  "pickup":  { "lat": 41.311, "lon": 69.279 },
  "dropoff": { "lat": 41.330, "lon": 69.250 },
  "pickup_address":  "Amir Temur Square",
  "dropoff_address": "Inha University in Tashkent"
}
```

`201 Created`

```json
{
  "id":           "5a8d…",
  "status":       "requested",
  "requested_at": "2026-04-27T13:42:11.523Z"
}
```

The matcher then pushes a `trip.matched` event over the WebSocket gateway
within ~1–2 s; clients receive it in the `trip:event` channel after
`trip:subscribe(<id>)`.
